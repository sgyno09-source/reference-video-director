# 中文使用说明

## 一句话理解

把“参考图 + 一个剧情想法”变成可以直接交给视频模型的完整导演提示词。

## 推荐调用方式

```text
使用 reference-video-director。

角色：{{Mixed 1}}
服装：{{Mixed 2}}
场景：{{Mixed 3}}

时长：30 秒
模型：Seedance
视角：男友第一人称

剧情：
女友因为男友一句话开始假生气，
男友不会哄人，最后反而把她逗笑。

要求：
真实情侣日常，不要偶像剧感，
对白自然，重点表现微表情和憋笑。
```

## 推荐输出重点

真实情侣视频不要靠“情话”制造恋爱感。

更有效的是：

- 半秒停顿
- 抬眼
- 抿嘴
- 偷偷看回来
- 想笑又忍住
- 手碰到以后真实退开
- 一句一本正经但很笨拙的回答

## 如果用户只给一句话

不要追问大量参数。

可以自动补齐保守默认值，再把不确定项写成容易修改的部分。
