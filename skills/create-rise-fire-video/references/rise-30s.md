# 30秒 RISE 连续镜头基线

## 基础与参考职责

采用16:9横屏、30秒、真人写实电影摄影。无字幕、无额外文案、无配乐、无水印或Logo；RISE仅作为剧情中的实体燃烧结构。帧率沿用用户指定值，未指定时默认60fps。全片同一成年女性，严格绑定@image_1唯一身份参考，保持五官、脸型、肤色、年龄、身材、发型、服装与配饰，不因远景、烟雾、火光或仰拍变脸变老。

使用夜晚开阔草地暗场和深色单人椅。参考图的大火仅用于最终火势规模、光影和视觉气质；开场不能出现已燃烧背景或已形成文字。默认人物短发、黑色贴身都市服饰；具体人物外观以当前参考图为准。

保持自然皮肤纹理、轻微胶片颗粒、柔和辉光和真实火焰层次。避免赛博朋克、CG塑料皮肤、二维火焰贴图和过曝白背景。焦点连续跟随人物，不用失焦掩盖变脸或动作错误。

## 表演、姿态与道具

女主冷静、松弛、从容、克制、轻微疏离；表情幅度约10%–20%，保留呼吸、眨眼与细小视线变化。全程不回头，不因火势惊吓，不邪笑、挑眉、刻意眯眼或抬下巴摆造型。形成背景愈猛烈、人物愈平静的反差。

第一帧已真实坐在椅面，骨盆稳定，腰背自然，双腿向前不交叉，双脚落地。0–22秒保持普通坐姿，20–22秒仅上半身靠回椅背，22秒后才首次抬腿；画外也不能提前交叉。关节、肢体长度和空间关系连续。

左手始终负责同一火柴盒：持盒、稳定划燃、点烟后降至腰侧、最终握盒放松停在扶手附近。盒子不消失、不变形、不换手。

右手依次推开盒内抽屉、抽出一根木质火柴、一次划燃、点烟、继续握着同一燃烧火柴、向侧后方抛出、空手自然回落。使用可覆盖这段时长的较长木质火柴，燃烧持续推进，不烧尽后恢复或熄灭后重燃。

同一支香烟从开场到结尾轻含嘴角，不继承参考图手持烟姿势，不用手取下或在手嘴间跳转。仅两只手、一根火柴、一支烟，禁止多手、手指增生融合和道具穿掌。

开场烟草端为完整白色卷烟纸包裹的浅棕/黄褐色细烟丝截面。0–8秒完全未燃烧：无焦黑、灰烬、红点、橙点或烟雾。8–10秒火焰接触并配合吸气以后才由浅棕烟草→局部受热→小范围橙红核心→吸气变亮→少量焦化边缘→少量浅灰新鲜灰烬，不能瞬间整颗发黑或长灰。

## 摄影机唯一轨迹

采用真实摄影机沿原中轴后退、固定焦距、一条连续轨迹，无切镜、绕拍、火柴追踪、数字变焦、突然升降或瞬移。摄影机高度连续稳定，朝向随后退平滑上仰，逐步释放头顶空间。焦点自然跟随人物，不突然转焦背景或火柴。

| 时间 | 后退与仰角 |
|---|---|
| 0–12秒 | 近景基本稳定，接近平视约0°–2° |
| 12–16秒 | 很轻微连续后退，约2°→3° |
| 16–18秒 | 约3°→5°；约17秒火柴离手后平滑加速后退 |
| 18–20秒 | 持续后退，约5°→7° |
| 20–22秒 | 持续后退，约7°→9° |
| 22–24秒 | 持续后退，约9°→11° |
| 24–26秒 | 持续后退，约11°→13° |
| 26–28秒 | 持续后退，约13°→15° |
| 28–30秒 | 同轨迹极轻微后退并减速，约12°–15°，无明显回摆 |

角度是连续曲线，不能逐段重设机位；不明显超过15°。不要后拉停住再构图，也不要最后一秒补新机位。空间不足时提前沿原轨迹继续后退，不能裁切、变焦、缩短肢体或让字母侵入人物。

## 动作时间轴

| 时间 | 必须发生的动作与状态 |
|---|---|
| 0–2秒 | 近景包含脸、未燃香烟、左手火柴盒和右手。视线略向下，左手稳持盒，右手推开抽屉，背景暗场无大火和文字。 |
| 2–4秒 | 右手抽出唯一完整木质火柴并调整握法，靠近摩擦面，尚未点燃。 |
| 4–6秒 | 一次短促真实摩擦：接触→快速划过→少量细火星→点燃→稳定小橙黄火焰。剩余时间自然停顿，暖光映指尖、下巴、嘴唇与鼻尖下方。香烟未燃。 |
| 6–8秒 | 同一根燃烧火柴由胸前平稳靠近烟草端面；8秒前不完成接触点烟，头基本稳定。 |
| 8–10秒 | 火焰真实接触烟草端面，女主吸入第一口，烟头连续受热点燃，约10秒完成。近景不急退。 |
| 10–12秒 | 完成第一口，少量暗红核心、新灰和焦化边缘。右手移开仍燃烧火柴，停在侧前方远离发服；左手握盒降低，视线回镜头附近。 |
| 12–14秒 | 香烟仍含嘴角，从唇间缓慢吐出小股轻薄半透明烟雾，向脸前和侧边散开，不遮五官。镜头第一次轻退，由脸部近景扩至头肩。 |
| 14–16秒 | 烟漂散；轻退露出上身、部分椅背、腰和双臂。右手携同一燃烧火柴移至身体侧边准备后抛；左手握盒；双腿未交叉。 |
| 16–17秒 | 肩轻带动→上臂侧后移→肘与前臂跟随→腕甩→松指，约17秒火柴真实离手。绕开身体及椅背，不穿模，不回头。镜头从离手瞬间平滑加速后退。 |
| 17–18秒 | 火柴按重力正常飞行、下降，约18秒接触后方预设可燃区域。呈小而可辨暖色火点，无火球、悬浮、慢动作、瞬移或第二根火柴。镜头不追火柴。 |
| 18–20秒 | 真实接触后才局部点燃，第一小簇火苗稳定并向邻近连续路径蔓延。退镜逐渐露出女主、椅子、未交叉双腿、环境与落点，不能瞬间火海或完整RISE。 |
| 20–22秒 | 火舌沿预设路径向上及两侧扩展，部分RISE路径显露未完整。女主腰背放松、肩后移、上身靠椅背，骨盆留椅面，腿仍不交叉。发、肩、衣、椅开始暖橙轮廓光。 |
| 22–24秒 | 第一次抬腿：脚离地→大腿轻升→膝弯→小腿抬起→跨向另一腿上方，方向对应参考最终姿势。无瞬移、穿模、骨盆离椅或腿长变化；R/I/S/E逐步可辨仍在形成。 |
| 24–26秒 | 自然跨腿并稳定二郎腿，约25.5秒头顶至双脚及完整椅子入画。双臂、双手、腰胯、两膝、两小腿和两脚可区分，交叠处不错误融合消失。之后不再裁身体。 |
| 26–28秒 | 沿原轨迹继续退，约27秒完整人物、椅子、二郎腿、双脚和完整R/I/S/E同在画内。人物和字母之间清晰暗隙；不追加动作，不回头，左手仍握盒、右手松弛、嘴角仍含烟。 |
| 28–30秒 | 同轨迹减速维持完整动态大景。人物靠椅背、二郎腿、平静看镜头；保留呼吸、少量细烟、火焰翻滚及少量上升火星，不冻结最后帧。 |

## 火焰文字连续燃烧

在后方预先存在黑暗、未燃、不发光的可燃结构及连续传播路径。火柴落地后起火，沿路径蔓延，逐步显露更远、更高的巨大RISE。路径连接部分保持低而不抢眼，最终四字母之间仍有暗隙，不成为火墙。

从左到右仅R、I、S、E，非贴图、霓虹Logo、悬浮字幕、后期文字、简单实体发光或黑暗淡入。

- R：左竖、完整上弧、明确右下斜腿，内部暗腔；不变P/B/K。
- I：独立竖向主体，可有上下短横，与邻字隔开，不消失或融合。
- S：完整连续上弧、中转折和下弧，以负空间辨认；不变5或碎火团。
- E：左竖和上中下三横，右侧开放，不变F或缺底横。

以真实翻滚火舌、白橙亮核心、橙黄主体、深橙红外围和暗色空腔建立结构。允许收缩扩张、少量火星、轻微热浪及适量上升烟，字母不能波动成其他字或断裂不可辨，火光不能填满空腔。尺度明显大于人物，但不侵入人物轮廓。

## 最终无遮挡与三层空间

最后至少2秒同时完整显示女主全身、完整动作、完整深色椅子、自然二郎腿、两小腿、双脚及完整R/I/S/E，任何元素不被框裁、烟火遮挡或错误融合。

1. 下方中央前景：人物与椅子，整体高度约画面42%–48%，不超过50%，从头到脚清晰，无火焰侵入。
2. 中间：明显暗色负空间，仅少量半透明烟与轻热浪，分开人物和字母。
3. 更远、更高背景：巨大完整横排RISE；R左后、I左中后、S右中后、E右后，主体与主要火舌均在人物轮廓外。

RISE最低火舌高于头顶，间隙建议约画面高度5%。脚底至下沿留5%–8%地面，最高火舌至上沿留5%–8%，字母两侧留明确边距，考虑火焰动态波动。不能人物挡字、字穿头、火覆盖发肩臂躯干腿脚或椅子。最终画面不照搬参考图裁腿或挡字构图。

## 烟雾与人物受光

香烟烟雾少量、轻薄、半透明，停留嘴边、脸侧及少量中层空气，不遮脸、手、腿、脚或椅子。火烟向上，不遮RISE或堆积前景。烟雾不用于掩盖错误。

火光仅提供发边、肩、黑衣和椅边暖橙勾边及少量自然皮肤反射；正面较冷较暗但可辨认。禁止整脸异常红、全身变橙、永久变肤色、灼伤、头发衣椅起火、身体冒火、变老或热浪融脸。

## 合并负面约束

禁止开场灰烬/黑烟头/燃烧/冒烟；禁止香烟换手或离嘴；禁止22秒前交叉腿、瞬间成二郎腿、穿模、缺腿脚或腿长变化；禁止第二火柴/香烟、第三手、道具跳变、火柴盒消失、火柴悬浮瞬移及燃烧倒退；禁止落地前起火、RISE突然出现、淡入文字、VSC、额外文字、错字缺笔画；禁止第二机位、切镜、数字变焦、突然后拉/仰拍/升降/尺寸跳变、慢动作或结尾冻结；禁止变脸、变短发、变年龄身材衣服、塑料皮肤；禁止裁人物/椅子/字母任何边缘、人物火字互遮及浓烟遮挡。
