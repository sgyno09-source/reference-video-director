# RISE 火焰电影提示词

将用户参考图与要求转化为可直接复制的视频提示词。默认用中文，采用30秒、16:9、真人写实电影摄影、单一连续镜头，以RISE为背景燃烧文字。不要把提示词编写误报为已生成视频。

## 执行流程

1. 读取 [完整方案](references/rise-30s.md)，以其中时间表和状态约束为默认基线。
2. 从当前用户要求提取人物参考、文字、时长、画幅与其他明确修改。用户当前要求优先；未要求修改的部分保留。不要沿用早期15秒版本的时间标记或VSC文字。
3. 将当前人物图绑定为唯一身份参考。若只编写提示词且未提供图，使用“@image_1（请绑定你的人物参考图）”占位符继续，不假装看过图片；若用户要求根据缺失图片实际生成内容，再要求补充。不要把旧图当作当前可用附件。
4. 仅将参考图用于人物身份、服装及最终视觉气质。明确排除继承参考图中的开场大火、手持香烟、提前二郎腿、裁腿或人物遮字构图。默认保留短发、黑色服饰；用户更换人物图时以该图为准，不强行把人物改成旧角色。
5. 输出完整、独立可用的提示词，按基础参数、参考图职责、人物/道具状态、摄影机轨迹、逐段时间轴、火焰文字、最终构图、负面约束排列。不要只输出摘要或要求用户拼接前文。
6. 输出前检查动作和时点是否一致。将重复禁止项合并，保留所有改变状态、因果或构图的关键限制。

## 变体处理

- 改文字：同步替换全片文字、最终验收和负面约束；根据新字母写清笔画与暗色间隙，不遗留RISE或VSC。文字更长时通过提前持续后退释放空间，保留人物和完整字母。
- 改时长：按用户明确要求重排全部时间轴。无指定节奏时按新时长/30等比例缩放默认节点，包括22秒抬腿、25.5秒全身和27秒完整字母节点；为结尾动态完整构图尽量保留至少2秒。动作太多且时间不足时简洁说明冲突并给出具体节奏选择，不偷偷删核心动作或承诺一定生成成功。
- 改画幅：重新安排人物占比和文字位置、边距；保留三层空间、全身和字母互不遮挡。不要直接套用16:9比例数值。
- 改人物：绑定新图，同步更新发型、服装和身份描述，保持动作职责及状态连续。不要从旧人物补入未提供的五官细节。
- 用户只改一项时，直接完成该项及必要连带修改，避免额外确认。
- 用户要求视频生成时，仅使用实际可用且已授权的生成能力；否则提供完整提示词并说明当前未生成视频。不要编造模型功能、费用或工具结果。

## 验收

默认30秒版本必须同时满足：8秒前烟草端未燃烧；左手始终持同一个火柴盒；右手使用并抛出同一根火柴；香烟始终在嘴角；约17秒离手、18秒落地后才起火；22秒后首次抬腿；镜头真实持续后退并连续增加仰角；约25.5秒全身、27秒完整RISE入画；最后至少2秒人物、椅子、双脚和四字母完整且互不遮挡。检查全片无二手持烟、无提前火海、无第二机位、无冻结结尾。
